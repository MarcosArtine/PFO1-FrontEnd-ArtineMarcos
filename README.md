## 🛠️ Herramientas Utilizadas y Desarrollo

En este apartado se detallan las herramientas empleadas para el diseño, desarrollo y estructuración del portfolio, junto con la experiencia previa y las decisiones de adaptación tomadas.

---

### 1. Herramientas y Uso

* **Visual Studio Code:** Editor de código principal utilizado para escribir y estructurar los archivos `index.html` y `style.css`.
* **Devicon:** Librería de fuentes e íconos vectoriales utilizada para representar visualmente las tecnologías y habilidades técnicas en la sección correspondiente.
* **Google Fonts:** Servicio de tipografías web utilizado para integrar las fuentes *Montserrat* y *Open Sans*.
* **Gemini (Google AI):** Modelo de lenguaje de inteligencia artificial utilizado como asistente de desarrollo para estructurar el código HTML/CSS, diseñar la maquetación responsive y optimizar la accesibilidad mediante atributos ARIA.

### 4. Revisión, Cambios y Criterio Propio Aplicado

A pesar de contar con la ayuda del asistente de IA para la generación del código base, apliqué mi propio criterio técnico para adaptar el proyecto a mis necesidades reales:

* **Estructura y Contenido:** Revisé y corregí toda la información personal, incorporando mis estudios actuales (IFTS N° 29), cursos realizados y enlaces reales (GitHub y correo electrónico).
* **Estilos y Paleta de Colores:** Modifiqué la paleta CSS global mediante variables (`:root`) para darle un tono oscuro moderno (*Dark Mode*), asegurando un buen contraste visual y legibilidad.
* **Rediseño de Habilidades:** Reemplacé las etiquetas simples de texto por íconos de la librería **Devicon**, aplicando la versión `wordmark` con la clase `colored` para mostrar cada tecnología con su color distintivo oficial.
* **Optimización de Accesibilidad (ARIA):** Añadí etiquetas `aria-label`, `aria-labelledby` y `aria-required` para garantizar que la página sea completamente accesible mediante lectores de pantalla, respetando el uso correcto del HTML5 semántico.
